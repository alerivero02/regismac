🚀 PASO 2: GITHUB REPOSITORIO
═══════════════════════════════════════

1. En Brave, ve a: https://github.com/new

2. Configuración del repositorio:
   - Repository name: regismac
   - Description: Sistema de gestión de producción RegisMAC
   - Visibility: Public (o Private si prefieres)
   - ⚠️ NO marques "Initialize with README"
   - ⚠️ NO agregues .gitignore ni license
   - Click en "Create repository"

3. Después de crear el repositorio, GitHub te mostrará instrucciones.
   Copia la URL del repositorio (formato: https://github.com/TU_USUARIO/regismac.git)

4. En tu terminal, ejecuta estos comandos (reemplaza TU_USUARIO con tu usuario):

   git remote add origin https://github.com/TU_USUARIO/regismac.git
   git push -u origin main

5. Si te pide autenticación, usa un Personal Access Token de GitHub

═══════════════════════════════════════
✅ Cuando termines, escribe: "GITHUB LISTO"
